MC 전단지 인쇄관리 프로그램 v1.3
======================================

■ 실행 방법 (Windows PC)
1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 [모두 압축 풀기]를 선택합니다.
2. 압축을 푼 폴더에서 [실행하기.bat]를 더블클릭합니다.
   또는 index.html을 Chrome/Edge 브라우저로 열어도 됩니다.
3. 설치나 인터넷 연결은 필요하지 않습니다.

■ v1.3 변경사항
1. 앞면/뒷면 각각의 MC 정보 표시 여부 선택
   - [앞면에 표시]만 체크: 앞면에만 MC 이름/연락처를 넣습니다.
   - [뒷면에 표시]만 체크: 뒷면에만 넣습니다. (기본값)
   - 두 면 모두 체크: 양면 각각에 동일한 MC 정보를 넣습니다.
   - 앞면 미등록 세트에서는 앞면 표시를 선택할 수 없습니다.
   - 적어도 한 면은 체크해야 저장할 수 있습니다.
2. 문구 기본값: 글자 크기 20pt / 두께 '아주 굵게'(900) /
   가로 위치 50% / 세로 위치 94.7%
3. 글자 크기는 8~96pt를 숫자로 직접 설정할 수 있습니다.
   따라서 20pt를 넘는 큰 글자도 사용할 수 있습니다.
4. 문구 표시 면과 글자 설정을 출력 보관함에 함께 저장합니다.
   - 이전 버전에서 저장된 출력본은 기존과 같이 뒷면에 MC 정보만 표시합니다.
5. 인쇄될 앞면/뒷면을 미리보기 버튼으로 확인할 수 있습니다.
6. PNG 저장 시 지금 미리보고 있는 면(앞면 또는 뒷면)을 저장합니다.
   출력 보관함에서는 앞면 PNG와 뒷면 PNG를 별도로 저장할 수 있습니다.

■ 전단지 한 세트 등록
1. [03 · 전단지 관리]에서 전단지 세트 이름, 앞면 이미지, 뒷면 이미지를 등록합니다.
2. A4 세로형/가로형 자동 인식 또는 수동 선택이 가능합니다.
3. 기존 세트에 앞면을 추가하려면 해당 카드의 [면 편집]을 누르세요.
4. 기본 제공: 세로형 3종 뒷면 + 가로형 워커힐 매트리스 3종 비교 앞뒷면 세트.

■ MC를 선택하고 인쇄하기
1. [02 · 담당 MC 관리]에서 이름·전화번호를 등록합니다.
2. [01 · 전단지 제작·인쇄]에서 전단지 세트와 담당 MC를 선택합니다.
3. [MC 문구 · 표시할 면 설정]에서 앞면 / 뒷면 / 양쪽 체크 여부를 정합니다.
   - 글자 크기, 두께, 색상, 가로/세로 위치를 조정합니다.
   - [앞면] [뒷면] 미리보기 버튼으로 각 면의 배치를 확인합니다.
4. 용지 방향을 A4 세로형 또는 가로형으로 정합니다.
5. 인쇄 방식을 단면/양면으로 선택합니다.
   - 양면: 1페이지 앞면 → 2페이지 뒷면. 선택한 면에만 MC 문구가 들어갑니다.
   - 단면: 앞면 또는 뒷면 중 선택한 한 페이지만 출력합니다.
6. [출력본 저장] 또는 [저장하고 인쇄]를 누릅니다.
   인쇄 창에서 프린터 또는 [PDF로 저장]을 선택하세요.

■ 프린터 설정
- A4 용지 / 배율 100% / 여백 없음 권장.
- 세로형 양면: 일반적으로 긴쪽 넘김.
- 가로형 양면: 일반적으로 짧은쪽 넘김.
- 프린터별 양면 반전 옵션이 다를 수 있으므로 실제로 1장 시험 출력해 보세요.
- 무테 인쇄를 지원하지 않는 프린터는 가장자리 일부가 잘릴 수 있습니다.

■ 출력 보관함 / 백업 및 복원
- [04 · 출력 보관함]에서 이전 출력본 재인쇄 및 설정 불러오기가 가능합니다.
- 출력 기록은 현재 PC/브라우저의 저장소에 저장됩니다.
- v1.2에서 사용 중이었다면 v1.2를 열고 [전체 데이터 백업]을 먼저 실행해
  JSON 백업 파일을 보관해 두세요. 새 버전의 [04 · 출력 보관함] →
  [백업 복원]에서 복원할 수 있습니다.
- 백업 복원은 프로그램에 현재 저장된 내용을 대체하므로 주의하세요.
- 브라우저나 실행 폴더가 달라지면 기존 데이터가 보이지 않을 수 있습니다.
- 인쇄 후 실제로 종이가 출력됐는지는 프로그램에서 확인할 수 없습니다.

※ 원본 전단지의 사진, 설명, 가격은 수정하지 않고 지정된 MC 문구만 덧씌워 출력합니다.
